Проект был сделан на Python и HTML.

Работа представляет из себя платформу для учеников и репетиторов. Используется асинхронная БД. 
В качестве аутентификации используются файлы Cookie, хранящие JWT токены, живущие в течение часа.

Проект запущен на хостинге Render
Ссылка: https://teacherstudents.onrender.com/

## Технологии: 
1. FastAPI 
2. Bcrypt
3. sqlalchemy
4. python-jose[crypthography]
5. uvicorn

## Запуск
1. Установить репозиторий
2. Перейти в папку
3. Запустить команду: python -m uvicorn main:app --reload

## Функции
1. Роли ученик/репетитор
2. Бронирование и отмена
3. Отзывы и рейтинг
4. Рекомендации
5. Работа с объявлениями
